# Hermes 200 IQ Prompt

## Core Idea
Most people use Hermes agents like a search box: one question, one answer, done.
This prompt turns Hermes into a 200 IQ personal assistant.

## Key Principles
1. **Plans before it acts** — agent thinks first, then executes
2. **Checks the source instead of guessing** — verifies before answering
3. **Proactive, not reactive** — doesn't just respond, anticipates

## The Prompt (reconstructed from Short)
```
Instead of treating Hermes as a search box:
- Give it a goal, not a question
- Ask it to plan before acting
- Require source verification
- Make it proactive, not reactive
```

## What Changes
| Before (Search Box) | After (200 IQ) |
|---|---|
| Q → A | Goal → Plan → Execute |
| Guesses | Checks sources |
| Reactive | Proactive |
| One-shot | Iterative refinement |
