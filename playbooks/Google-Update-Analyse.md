# Google Update Analyse

## Eingabe
- Google Update Name/Datum
- Kunden-URLs

## Schritt 1: Recherche
- Offizielle Google Dokumentation lesen
- Search Engine Roundtable checken
- Community Reaktionen sammeln

## Schritt 2: Impact-Analyse
Für jede URL prüfen:
1. Betroffen? (Ja/Nein/Unklar)
2. Ranking-Change
3. Traffic-Impact

## Schritt 3: Report
- Zusammenfassung für Kunden
- Empfehlungen
- Nächste Schritte

## Tools
- OKF Brain (References + Playbooks)
- Hermes Agent
- Browser für Recherche
